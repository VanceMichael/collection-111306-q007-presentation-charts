# 本地资料源约定

fixtures/capacity.pptx 是 ZIP 封装文稿，具有 slides、rels、charts 和真实嵌入 XLSX。两页引用同一图，缓存与工作簿数值不同，并有外部资源关系。现有 archiveEntries 只提供资源浏览，不做图表采集。GET /api/package 领取原始文稿。

## 通用控制

`GET /api/snapshot` 查看当前原始源状态；`POST /api/action` 接收 JSON 对象 `{"action":"动作名"}`。可用动作：reset。控制只改变模拟源，不代表接收器已经处理了变化。

所有资料均由本项目构造，包含的机构、设备、会话和文件仅供本地使用，不访问真实账号。浏览器操作应通过正常可见界面；测试用源控制接口不是业务采集捷径。

## 来源证据

源端请求记录只用于核查服务行为，接收器自身的审计、状态和输出需由扩展功能负责。源端重启会恢复默认资料，但本地接收文件不会自动清空。
